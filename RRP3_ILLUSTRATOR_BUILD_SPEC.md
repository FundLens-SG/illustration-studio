# RetireReady Plus (III) Illustrator Build Spec

Purpose: add a RetireReady Plus (III) module to Illustration Studio that estimates premiums and monthly retirement income from a parsed set of policy illustrations.

Important note to show prominently in the tool:

> Figures generated by this tool are extrapolated from uploaded policy illustrations and are approximate only. They are not official Manulife policy illustrations, are not guaranteed to be 100% accurate, and must be validated against an official policy illustration before client use or application.

## Product Features To Carry Into The Tool

Source reviewed: `C:\Users\user\Downloads\Manulife RetireReady Plus (III) Technical Training Slides_14 Sep 2025.pdf`.

- Product type: single premium or limited-pay regular premium participating retirement income plan.
- Target market: clients age 18 to 65 seeking retirement income; unsuitable for high-protection, short-term endowment, or ILP needs.
- Premium payment terms: Single Premium, 5 years, 10 years, 15 years, 20 years.
- Selected retirement ages: 50, 55, 60, 65, 70.
- Income payout periods: 5 years, 10 years, 15 years, 20 years, Lifetime. Lifetime means to age 120.
- Single premium and 5-year premium term are not eligible for the 5-year income payout period.
- Guaranteed Monthly Income (GMI): minimum S$250/month, in multiples of S$10. Maximum GMI from deck: S$190,000.
- Retirement Income Benefit (RIB): monthly GMI plus non-guaranteed Cash Bonus (CB), if any.
- RIB starts 1 month after the policy anniversary on which the life insured attains the selected retirement age, and is paid over the chosen income payout period.
- CB is non-guaranteed, declared and vested annually starting from the policy anniversary immediately before the selected retirement age, then payable monthly with GMI.
- CB percentage varies by retirement age, income payout period, premium payment term, entry age, and gender.
- Illustrated investment return rates in deck: 4.25% p.a. higher illustration and 3.00% p.a. lower illustration.
- Accumulation option interest rates in deck: 3.00% p.a. under 4.25% IIRR and 1.50% p.a. under 3.00% IIRR.
- Premium rates are level and guaranteed, and vary by selected retirement age, premium payment term, income payout period, and entry age.
- Income payout period can be changed after inception, with no limit on number of changes, but only at least 2 years before selected retirement age. GMI is revised if payout period changes.
- Reduced Paid Up is possible after surrender value is acquired, but not applicable to single premium and not allowed during premium freeze.
- Premium Freeze: not applicable to single premium. 5-year term can freeze once; 10/15/20-year terms can freeze twice.
- Retrenchment Payout Benefit: individual-owned policies only; single premium pays 12.5% of single premium; regular premium pays 50% of annual mode premium. Not payable during premium freeze.
- Waiver of Premium on TPD: embedded for regular premium only, not single premium.
- Loss of Independence Income Benefit during payout period: 50% of GMI if unable to perform any 2 of 6 ADL, capped at S$2,000/month; 100% of GMI if unable to perform at least 3 of 6 ADL or specified severe conditions, capped at S$4,000/month.
- Death/TI, surrender, maturity, and optional riders should be summarized as product features but do not need to drive the first calculator unless the source illustrations contain extractable values for them.

## Eligibility Constants

Entry age is Age Last Birthday (ALB).

```js
const RRP3_RETIREMENT_AGES = [50, 55, 60, 65, 70];
const RRP3_PREMIUM_TERMS = ["single", 5, 10, 15, 20];
const RRP3_PAYOUT_PERIODS = [5, 10, 15, 20, "lifetime"];

const RRP3_ENTRY_AGE_LIMITS = {
  single: { 50: [18, 45], 55: [18, 50], 60: [18, 55], 65: [18, 60], 70: [18, 65] },
  5:      { 50: [18, 43], 55: [18, 48], 60: [18, 53], 65: [18, 58], 70: [18, 63] },
  10:     { 50: [18, 40], 55: [18, 45], 60: [18, 50], 65: [18, 55], 70: [18, 60] },
  15:     { 50: [18, 35], 55: [18, 40], 60: [18, 45], 65: [18, 50], 70: [18, 55] },
  20:     { 50: [18, 30], 55: [18, 35], 60: [18, 40], 65: [18, 45], 70: [18, 50] }
};
```

Validation rules to implement before generating any illustration:

```js
function validateRrp3Input(input) {
  const {
    currentAge,
    targetRetirementAge,
    premiumPaymentTerm,
    incomePayoutPeriod,
    guaranteedMonthlyIncome
  } = input;

  if (!RRP3_RETIREMENT_AGES.includes(targetRetirementAge)) {
    return "Selected retirement age must be 50, 55, 60, 65, or 70.";
  }

  if (!RRP3_PREMIUM_TERMS.includes(premiumPaymentTerm)) {
    return "Premium payment term must be Single Premium, 5, 10, 15, or 20 years.";
  }

  if (!RRP3_PAYOUT_PERIODS.includes(incomePayoutPeriod)) {
    return "Income payout period must be 5, 10, 15, 20 years, or Lifetime.";
  }

  if ((premiumPaymentTerm === "single" || premiumPaymentTerm === 5) && incomePayoutPeriod === 5) {
    return "5-year income payout is not available for Single Premium or 5-year premium payment term.";
  }

  if (targetRetirementAge <= currentAge) {
    return "Target retirement age must be above current age.";
  }

  const termYears = premiumPaymentTerm === "single" ? 0 : premiumPaymentTerm;
  const yearsToRetirement = targetRetirementAge - currentAge;

  const isSinglePremiumMinimum7Exception =
    premiumPaymentTerm === "single" &&
    currentAge === 45 &&
    targetRetirementAge === 50;

  if (termYears + yearsToRetirement < 7 && !isSinglePremiumMinimum7Exception) {
    return "Premium term plus years to retirement must be at least 7 years.";
  }

  if (premiumPaymentTerm !== "single" && targetRetirementAge < currentAge + termYears) {
    return "Target retirement age cannot fall inside the premium payment term.";
  }

  const [minAge, maxAge] = RRP3_ENTRY_AGE_LIMITS[premiumPaymentTerm][targetRetirementAge];
  if (currentAge < minAge || currentAge > maxAge) {
    return `Current age must be between ${minAge} and ${maxAge} for this premium term and retirement age.`;
  }

  if (guaranteedMonthlyIncome < 250 || guaranteedMonthlyIncome > 190000 || guaranteedMonthlyIncome % 10 !== 0) {
    return "Guaranteed Monthly Income must be S$250 to S$190,000, in multiples of S$10.";
  }

  return null;
}
```

## Extraction Pipeline

1. Use PyMuPDF first for text extraction. Use pdfplumber as a fallback for tables.
2. For every PDF, extract full text page-by-page and detect whether it is text-based, encrypted, or scanned.
3. Reject or flag encrypted PDFs that cannot be opened.
4. Detect product name and scenario fields from cover pages and summary pages.
5. Extract benefit values from key policy illustration pages:
   - current age / entry age
   - gender and smoker status if present
   - premium payment term
   - selected retirement age
   - income payout period
   - GMI
   - annual premium or single premium
   - total premiums paid
   - non-guaranteed monthly cash bonus or total monthly income under 4.25% and 3.00% illustrated returns
6. Save three files:
   - `source-data/rrp3-policy-illustrations/parsed/rrp3_raw_text.jsonl`
   - `source-data/rrp3-policy-illustrations/parsed/rrp3_normalized.csv`
   - `source-data/rrp3-policy-illustrations/parsed/rrp3_extraction_audit.csv`
7. Audit completeness: expected grid should cover age 40 and age 45 for every product-valid combination of retirement age, premium term, and payout period after applying the deck's entry-age matrix and the 5-year payout exclusion for single/5-year premium terms. For ages 40 and 45, this produces 181 expected product-valid combinations before duplicate checks. The final run found all 181 unique combinations, with 5 duplicate groups.

## Approximation / Extrapolation Model

Use the official PDFs as source anchors, then estimate between or outside anchors.

Recommended model:

1. Normalize premiums and bonuses to a rate per S$10 of GMI.
2. For exact matches on age, retirement age, premium term, payout period, and gender, use the parsed anchor directly.
3. For age between 40 and 45, linearly interpolate the normalized premium rate and CB rate.
4. For age outside 40 to 45 but inside product eligibility, linearly extrapolate from the 40/45 slope and mark result as lower confidence.
5. For missing combinations, use nearest valid neighbors by:
   - same premium term
   - same retirement age
   - same payout period
   - nearest age
   - then nearest years-to-retirement
6. Never extrapolate across gender unless only one gender exists in the source set; if doing so, show a warning.
7. For regular premium:

```js
estimatedAnnualPremium = premiumRatePer10Gmi * (requestedGmi / 10)
estimatedTotalPremiums = estimatedAnnualPremium * premiumPaymentTerm
```

8. For single premium:

```js
estimatedSinglePremium = singlePremiumRatePer10Gmi * (requestedGmi / 10)
estimatedTotalPremiums = estimatedSinglePremium
```

9. For non-guaranteed cash bonus:

```js
estimatedMonthlyCb425 = cashBonusRate425 * requestedGmi
estimatedMonthlyCb300 = cashBonusRate300 * requestedGmi
estimatedMonthlyIncome425 = requestedGmi + estimatedMonthlyCb425
estimatedMonthlyIncome300 = requestedGmi + estimatedMonthlyCb300
```

10. Round currency for display, but keep full precision in the model file.

Confidence labels:

- `source_exact`: exact parsed scenario.
- `interpolated`: age between available source anchors.
- `extrapolated`: age outside source anchors but within eligibility.
- `estimated_missing_neighbor`: scenario estimated from nearby combinations because the exact combination was missing.
