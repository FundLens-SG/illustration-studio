# Illustration Studio

Internal advisor working tool for **CKG / FundLens-SG** — projects Manulife InvestReady-family Investment-Linked Policy outcomes year-by-year for Singapore private-client / HNW illustrations.

Single-file vanilla-JS app, deployed via GitHub Pages. The simulator computes monthly cashflows for 9 product variants (5F1, 6F2, 7F5, 10F3, 10F5, 10F8, 13F10, IRG15F10, IRG20F10) and exposes the year-by-year strategy table for advisor edits.

The shipping artifacts are:

- `illustration-studio.html` — the live app (calculator + UI)
- `assets/illustration-studio-logo.svg` — brand mark (compound-growth glyph; matches the canonical CKG suite tile)
- `fund-library-afl.js` — bundled iFAST AFL fund library (~320 funds)
- `index.html` — meta-refresh redirect to the app
- `Illustration Studio - Paper Printout.pdf` — sample paper-print PDF generated by the build below

## Run locally

It's a static site. Any HTTP server works:

```bash
# Pick one
python -m http.server 8000
npx serve .
```

Then open http://localhost:8000/illustration-studio.html.

Opening `illustration-studio.html` directly from disk also works — fonts and the fund library load via relative paths.

## Build the paper-print PDF

The in-browser **Print / save PDF** button calls `window.print()`, which on most printer drivers produces a portrait A4 with the wrong layout. The proper paper deck is generated by a Playwright script:

```bash
npm install
npx playwright install chromium       # one-time, downloads the browser
npm run build:pdf                     # default output: ./Illustration Studio - Paper Printout.pdf
```

Options:

```bash
# Custom output path
npm run build:pdf -- --out "Wee Family - 10F5 balanced.pdf"

# Render the full 37-row annual projection (default is milestones only)
npm run build:pdf -- --full-table --out "Full schedule.pdf"

# Use a different entry point (rare)
npm run build:pdf -- --entry illustration-studio.html
```

Output is **A4 landscape**, 5 pages: Summary · Protection & access · Projection chart · Annual projection (split as needed) · Disclaimers. White-ish paper background, no rotated content, no interactive controls.

The script reads the live values from `illustration-studio.html` — variants, premium, age, hero number, chart canvas, annual table, composition legend, disclaimers — and re-composes them into a clean print deck. Edit `scripts/build-paper-pdf.mjs` to change page order, branding, or layout.

## Save / Load scenarios

The top **`Save ▾`** dropdown offers three paths:

| Action | Where it goes | Persists across browsers? |
|---|---|---|
| Update autosave | `localStorage["ckg-illustration-autosave"]` | No |
| Save as new scenario… | `localStorage["ckg-illustration-save:<name>"]` | No |
| Download HTML… | File saved to disk; uses the named-save name if available, otherwise `illustration-studio-<variant>-<date>.html` | Yes (you control the file) |

The matching **`Open ▾`** dropdown lists the latest autosave, every named save (with timestamp + delete ×), and a `Open HTML from disk…` action that loads any HTML scenario file produced by the Save action.

**Autosave** fires 1.2s after every meaningful input change. The status caption next to the dropdowns reads `Autosaved · 10:37 am` in brass when fresh, amber if a write fails. On next visit the app starts from the default preset but offers a one-click `Restore latest autosave` in the Open menu.

## Google Drive integration (optional)

The Save / Open dropdowns are pre-wired for Google Drive sync. Pure browser localStorage is the default; Drive activates when a client ID is configured.

To turn it on, add this to the `<head>` of `illustration-studio.html`:

```html
<meta name="ckg-google-client-id" content="<your-google-oauth-client-id>.apps.googleusercontent.com" />
```

Set up the OAuth client in Google Cloud Console → APIs & Services → Credentials:
- Application type: **Web application**
- Authorized JavaScript origins: the deployed origin (e.g. `https://fundlens-sg.github.io`)
- Drive API: enabled
- Scope at request time: `https://www.googleapis.com/auth/drive.appdata`

When configured, the Save / Open menus get an additional `Drive` section listing scenarios stored in the app's hidden Drive `appDataFolder`. Without configuration the menus quietly fall back to localStorage.
